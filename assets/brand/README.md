# nuuAI brand assets

Concept A "≈ Approx": two waves that read as ≈ (an estimate) and as an analog signal. Tagline: **ANALOG INTELLIGENCE**.

All SVGs are outlined (no font needed). PNGs have a transparent background except the icons.

| File | Use |
| --- | --- |
| `nuuai-logo.svg` / `.png` | Main logo on light backgrounds |
| `nuuai-logo-dark.svg` / `.png` | On dark backgrounds |
| `nuuai-logo-tagline.svg` / `.png` | With "ANALOG INTELLIGENCE", light backgrounds (pitch title slide) |
| `nuuai-logo-tagline-dark.svg` / `.png` | Same, dark backgrounds |
| `nuuai-symbol.svg` / `.png` | Symbol only |
| `nuuai-app-icon.svg`, `-512.png`, `-180.png` | App / social icon |
| `nuuai-favicon.svg`, `-64.png`, `-32.png` | Browser tab (`st.set_page_config(page_icon=...)`) |
